# Basic CRUD Application

A simple web application developed using **PHP** and **MySQL** to perform CRUD (Create, Read, Update, Delete) operations with secure user authentication.

## 📌 Features

- User Registration
- User Login
- Password Hashing
- Session Management
- Create Posts
- Read Posts
- Update Posts
- Delete Posts
- MySQL Database Integration

## 🛠 Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

## ⚙️ Installation

1. Clone this repository.
2. Copy the project folder into the **htdocs** directory of XAMPP.
3. Start **Apache** and **MySQL**.
4. Import the **blog.sql** file into phpMyAdmin.
5. Open your browser and visit:

```
http://localhost/Basic-CRUD-Application/
```
